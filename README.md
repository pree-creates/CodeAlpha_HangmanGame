# Technology Hangman Game

## About the Project
This is a simple text-based Hangman game developed using Python as part of my CodeAlpha Python Programming Internship.

The player has to guess a hidden technology-related word by entering one letter at a time.

## Features
- Random selection of words.
- Maximum of 6 incorrect attempts.
- Displays correctly guessed letters.
- Prevents repeated guesses.
- Rejects invalid inputs.
- Displays win or lose messages.

## Technologies Used
- Python 3
- VS Code

## Python Concepts Used
- Random module
- While loop
- For loop
- If-else conditions
- Strings and lists
- User input

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run `hangman.py`.
4. Enter one letter at a time to guess the hidden word.
